# Changelog

All notable changes to this project will be documented in this file. The
project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.6.0] - 2026-10-25

- Add Pi and OMO native forks with owner-bound live settings, original product identity and child bridge registration.
- Add conditional OpenCode `mini --fork` and private Copilot `sessions.fork` adapters; require trusted source IDs and verify independent child IDs.
- Recognize Cursor, Antigravity and Hermes but reject unsafe automatic paths before creating a panel; no concurrent source resume or speculative storage import.
- Keep unverified new read-only modes disabled, and document configuration-root and provider/E2E limitations.
- Handle Node process-title argv truncation, excluded flag values and inherited plugin-state-root conflicts.
- Cover identity, workflow and bounded native RPC branches; validate Pi/OMO fixture inheritance and Copilot native event durability without model calls.

## [0.5.0] - 2026-10-25

- Rename the plugin to Panel Fork, ID `seungwonme.panel-fork`.
- Make normal native forks the CLI and primary-action defaults without question-only restrictions.
- Keep read-only behavior as an explicit separate action and mode.
- Update the approved Ctrl+B, then f binding and cover all primary actions in regression tests.

## [0.4.0] - 2026-10-25

- Personal question-fork actions for Claude, Codex, OMP and GJC.
- Native current-point forks with child-only question policy and read-only tools.
- Exact owner bridge for GJC/OMP, live model settings and stale-identity refusal.
- Preserve failed destinations and distinguish pending Codex identity from success.
- Runtime guard tests and macOS native fork QA; no global rules or existing hook edits.

## [0.3.0] - 2026-08-10

### Added

- Native Codex and Claude Code session forking from Herdr's trusted session ID.
- New-tab, split-pane, and new-workspace destinations.
- Automatic opening and verification of each agent's earlier-message picker.
- Visible failures and destination-specific cleanup without transcript mutation.
- A dependency-free test and verification harness.
